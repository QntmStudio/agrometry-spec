Agrometry

An open standard for in-field agricultural measurements.

Status: v0, draft. Not yet validated on real hardware. Everything may change. Not for production use.

A low-cost sensor node in a field should be able to say what it measured, how it was calibrated and where the data came from, in a form that researchers, integrators and platforms can verify independently. Agrometry defines that record, a compact LoRaWAN-sized binary frame, a calibration attestation and a signed batch receipt. It reuses SenML, SOSA and PROV-O instead of reinventing them.
